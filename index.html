☁️ وإن كان التطبيق مغلقًا على كل الأجهزة، يرد البوت من خادم GitHub تلقائيًا خلال 5–15 دقيقة (ويرسل التقفيل التلقائي أيضًا).
الخطوات: 1) راسِل @BotFather وأنشئ بوتًا، والصق Token أعلاه. 2) افتح بوتك في Telegram واضغط Start وأرسل له أي كلمة. 3) اضغط «🔎 جلب تلقائيًا» فيُكتب Chat ID وحده. 4) «إرسال رسالة تجريبية» ثم «حفظ».
