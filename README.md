# إدارة المغاسل

تطبيق بسيط لإدارة المغسلة، بملف واحد.

## كيف يعمل

- **ملف واحد فقط:** `index.html` — لا خطوة بناء، لا حزم، لا `npm install`.
- **بدون تسجيل دخول:** يفتح مباشرة على العمل.
- **الحفظ:** البيانات تُحفظ على الجهاز في `localStorage`، وتُزامَن مع Firestore
  في مستند واحد (`appState/main`) حتى تفتحه من أكثر من جهاز.
- **يعمل بدون إنترنت:** إذا انقطع الاتصال يكمل محلياً ويزامن عند عودته.

## التشغيل محلياً

افتح `index.html` في المتصفح مباشرة، أو:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## النشر

```bash
firebase deploy --only hosting,firestore:rules
```

الرابط بعد النشر: https://pressing-sadaga.web.app

> عند أول نشر بعد هذا التغيير، لا تنسَ نشر `firestore.rules` — القواعد السابقة
> كانت تمنع المسار `appState/main` الذي يستخدمه التطبيق، وبدون تحديثها ستعمل
> النسخة محلياً فقط بدون مزامنة.

## ملاحظة أمنية

مستند `appState/main` مفتوح للقراءة والكتابة لمن يعرف معرّف المشروع (وهو ظاهر
داخل `index.html`). بقية قاعدة البيانات مغلقة بالكامل. لإغلاقه: فعّل
Email/Password في Firebase، أضف تسجيل دخول للتطبيق، وغيّر القاعدة إلى
`allow read, write: if request.auth != null;`
