# إدارة المغسلتين

تطبيق ويب لإدارة مغسلة/مغاسل — ملف HTML واحد مكتفٍ بذاته (التنسيقات والمنطق مضمّنة)، يعمل مباشرة في المتصفح بلا أدوات بناء.

## التشغيل

افتح `index.html` في المتصفح، أو شغّل خادمًا محليًا:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## ملاحظات

- التطبيق يخزّن بياناته محليًا في المتصفح، مع تهيئة سحابية اختيارية.
- الخط الوحيد الخارجي هو Google Fonts (Tajawal) ويتراجع تلقائيًا إلى خطوط النظام.

هذه نقطة الانطلاق للعمل على التطبيق وتطويره.
