# تطبيق جديد

نقطة انطلاق نظيفة لتطبيق ويب — HTML و CSS و JavaScript فقط، بلا أدوات بناء.

## التشغيل

افتح `index.html` مباشرة في المتصفح، أو شغّل خادمًا محليًا:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## البنية

```
index.html          # الصفحة الرئيسية
assets/css/style.css # التنسيقات (فاتح/داكن، RTL)
assets/js/app.js     # منطق التطبيق
```

## الحالة

المشروع فارغ وجاهز للبناء. الميزات تُضاف خطوة بخطوة.
